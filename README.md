# Búsqueda del Tesoro AR — Sacré Coeur

El juego tiene tres marcadores. Cada marcador, al ser detectado por la cámara, hace aparecer un objeto 3D flotando junto con el texto de la pista correspondiente. Arriba de la pantalla hay una barra de progreso que se va completando a medida que se encuentran las pistas, y cuando el jugador ya escaneó las tres aparece una pantalla final dorada con un mensaje de "tesoro encontrado".

## Cómo probarlo

El juego está publicado en:

**https://manuruiz5.github.io/laboratorio-ar/**

Hay que abrirlo desde el celular y aceptar el permiso de cámara. Al entrar aparece un cartel de "Cómo jugar" que explica el juego y tiene un botón para ver los marcadores.

Los tres marcadores están en `marcadores.html`que permite validar el funcionamiento:

**https://manuruiz5.github.io/laboratorio-ar/marcadores.html**
